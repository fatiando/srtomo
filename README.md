## About

**SrTomo** (pronounced "Señor Tomo") is a Python package made for teaching
fundamental concepts in linear inverse problems. It makes it simple to calculate
Jacobian/sensitivity matrices for the straight-ray travel time tomography
problem, plot data and results, and implement different types of regularization.

## Project status

**SrTomo is in early stages of design and implementation**. This means that APIs
and results may change between releases.
